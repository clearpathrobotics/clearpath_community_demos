# hello_clearpath

A minimal "hello world" community demo for Clearpath platforms. Drives the
robot in a 1 m × 1 m square, with interchangeable C++ (`hello_square_cpp`) and
Python (`hello_square_py`) implementations to serve as starting templates for
new demos.

Build, run, and Docker Compose instructions are on the demo's documentation
page:
[Hello Clearpath](https://clearpathrobotics.github.io/clearpath_community_demos/demos_docs/hello_clearpath.html)
([source](../../demos_docs/hello_clearpath.md)).
