# Demos

This directory contains the source code for community-contributed demos. Each
subdirectory is a self-contained ROS 2 package (or group of packages) that can
be built with `colcon`.

See the [documentation site](https://clearpathrobotics.github.io/clearpath_community_demos/)
for write-ups of each demo and instructions on how to run them.

## Layout

```
demos/
├── hello_clearpath/                     # minimal example demo
├── unified_manipulation_config_ws/      # whole-body mobile manipulation example
└── <your_demo_here>/                    # add your contribution
```

To contribute a new demo, see the
[Contributing](https://clearpathrobotics.github.io/clearpath_community_demos/contributing/)
guide.
