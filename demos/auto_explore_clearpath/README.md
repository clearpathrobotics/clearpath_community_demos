# auto_explore_clearpath

Autonomous map exploration demo for Clearpath platforms on ROS 2 Jazzy. A
frontier-based explorer watches the live SLAM map, picks the nearest reachable
frontier, and sends goals to Nav2 until the map is covered.

Build, run, Docker Compose, and map-saving instructions are on the demo's
documentation page:
[Auto Explore Clearpath](https://clearpathrobotics.github.io/clearpath_community_demos/demos_docs/auto_explore_clearpath.html)
([source](../../demos_docs/auto_explore_clearpath.md)).
